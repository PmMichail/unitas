# UniTax — Універсальний Податковий AI-Асистент

UniTax допомагає українським підприємцям (ФОП) та компаніям (ТОВ) автоматизувати облік, парсити банківські виписки, вести податковий календар та автоматично генерувати податкові декларації (зокрема F0103306).

---

## Швидкий запуск (Docker Compose)

### Крок 1. Підготовка оточення
1. Створіть файл конфігурації `.env` на основі шаблону:
   ```bash
   cp .env.example .env
   ```
2. Відкрийте `.env` та вкажіть ваш Telegram Bot Token, отриманий від `@BotFather`:
   ```env
   TELEGRAM_BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
   ```

### Крок 2. Збірка та запуск контейнерів
Запустіть всю систему (База даних Postgres, Redis, Бекенд FastAPI, Фронтенд Next.js, Telegram-бот та сервіс Ollama) однією командою:
```bash
docker-compose up --build -d
```
Це автоматично:
- Створить схему бази даних у PostgreSQL.
- Додасть шаблон декларації `F0103306` у систему.
- Запустить веб-додаток на `http://localhost:3000`.
- Запустить API бекенду на `http://localhost:8000`.
- Запустить Telegram-бота.

## Інструкція для локального тестування (без Docker)

Якщо ви бажаєте протестувати код локально у вашому віртуальному оточенні:

### Крок 1. Запуск бекенду
1. Активуйте віртуальне оточення та запустіть FastAPI:
   ```bash
   source .venv/bin/activate
   uvicorn backend.api.main:app --reload --port 8000
   ```
   *Примітка: Бекенд автоматично створить локальну базу даних SQLite `unitas.db` у корені проекту.*

### Крок 2. Запуск Telegram-бота
У новому вікні терміналу:
```bash
source .venv/bin/activate
export TELEGRAM_BOT_TOKEN="ваш_токен_від_botfather"
python telegram_bot/bot.py
```

## Покроковий сценарій верифікації (Тестування)

### 1. Генерація тестових виписок
У проекті вже є вбудований скрипт для створення демонстраційних банківських виписок. Якщо ви ще не запускали його, виконайте:
```bash
python samples/generate_samples.py
```
Це створить у папці `samples/` наступні тестові файли:
- `samples/monobank.csv` (виписка monobank)
- `samples/oschad.html` (виписка Ощадбанку)
- `samples/pryvat24.pdf` (офіційний PDF-файл виписки Приват24 за березень 2025)
- `samples/abank.pdf` (виписка А-Банку)

### 2. Реєстрація ФОП у системі
1. Відкрийте вашого створеного бота в Telegram та натисніть `/start`.
2. Виберіть тип: **ФОП**.
3. Оберіть групу оподаткування: **3 група (5%)**.
4. Оберіть наявність працівників: **Ні**.
5. Введіть назву вашої компанії, наприклад: **ФОП Петренко Іван**.
6. Бот підтвердить успішну реєстрацію та повідомить, що створено податковий календар на 12 місяців.

### 3. Імпорт банківських виписок
1. Надішліть у чат бота команду `/upload`.
2. Прикріпіть файл `samples/monobank.csv` або `samples/pryvat24.pdf` як документ.
3. Бот завантажить його на бекенд, де `UniversalParser` автоматично визначить банк за структурою, витягне транзакції та запише їх у базу даних.
4. Бот відповість: `"Успішно завантажено! Вміст виписки розпізнано..."`.

### 4. Перевірка статусу "Оплачено vs Має бути"
1. Напишіть боту команду `/status`.
2. Бот покаже фінансовий звіт за березень 2025:
   - Обсяг доходу (сума зарахувань з виписок).
   - Нарахований податок (5% від доходу).
   - Сплачено податків (якщо у виписці були транзакції з призначенням "сплата єдиного податку" або "єсв").
   - Різницю та найближчі дедлайни з календаря.
3. Ви також можете відкрити веб-інтерфейс `http://localhost:3000/` у браузері, щоб побачити ці дані на інтерактивному дашборді.

### 5. Генерація декларації платника єдиного податку (F0103306)
1. У Telegram-боті надішліть команду `/report`.
2. Бот виведе інтерактивну чернетку декларації, де:
   - 🟢 Зеленим кольором підсвічені поля, отримані з банківських виписок (наприклад, сума доходу та сума податку).
   - 🟡 Жовтим кольором підсвічені дані профілю.
   - 🔴 Червоним кольором підсвічені відсутні обов'язкові реквізити (наприклад, ІПН).
3. Натисніть кнопку **"Завантажити XML"** під повідомленням бота. Бот надішле вам згенерований XML-файл, готовий для імпорту в електронний кабінет ДПС України.
