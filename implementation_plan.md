# План впровадження — Реструктуризація форми додавання об'єкта та уточнення початкового балансу

Цей план передбачає реструктуризацію модального вікна «Додати об'єкт» (додавання/редагування об'єкта) для розділення фізичних характеристик майна та даних мешканця, а також уточнення призначення поля початкового балансу.

## Необхідно переглянути користувачу

> [!IMPORTANT]
> Форма «Додати об'єкт» буде розділена на дві логічні вкладки: **Характеристики об'єкта** (для вулиці, номера ділянки/квартири, площі, тарифу) та **Дані мешканця** (для ПІБ, телефону, email, початкового балансу внесків, прапорців члена правління). Це дозволить відокремити налаштування об'єкта від даних мешканця.
>
> Ми також чітко підпишемо поле введення балансу як **Початковий баланс членських внесків (грн)**, щоб уникнути плутанини з комунальними послугами (наприклад, електроенергією).
